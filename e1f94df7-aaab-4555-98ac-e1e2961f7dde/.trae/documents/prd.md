## 1. 产品概述

市属拍卖行综合管理系统——覆盖春秋大拍与月度网络专场全流程数字化平台，年处理拍品8000件，涵盖瓷器、书画、珠宝、古籍等品类。解决纸质标签流转丢失、图录人工拼版耗时、保证金Excel遗漏、落槌结算差错率高、网络现场价差无法分析等核心痛点。

- 目标用户：拍卖行运营人员、鉴定师、图录编辑、拍卖师、委托人、竞买人六类角色
- 核心价值：拍品全流程可追溯、图录智能生成、保证金自动管理、结算零差错、数据驱动决策

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 超级管理员 | 系统初始化 | 全部权限、角色分配、系统配置 |
| 运营人员 | 管理员创建 | 拍品录入、拍卖会管理、图录编辑、数据看板 |
| 鉴定师 | 管理员创建 | 鉴定估值、会签意见、争议标记 |
| 图录编辑 | 管理员创建 | 图录排版、拖拽调整、PDF生成 |
| 拍卖师 | 管理员创建 | 主持拍卖、控制加价、落槌确认 |
| 委托人 | 自助注册 | 送拍申请、查看出价、结算查询 |
| 竞买人 | 自助注册 | 缴保证金、出价竞拍、结算提货 |

### 2.2 功能模块

1. **拍品全流程追踪**：各环节状态变更记录时间戳与操作人，编号查询当前节点
2. **智能图录生成**：按品类分组排序生成PDF，拖拽调整版式
3. **拍卖会管理**：设起拍价与加价幅度，现场网络同步出价，倒计时自动落槌
4. **保证金与结算**：缴保证金解锁参拍，落槌自动生成结算单，流拍自动退还
5. **鉴定估值协作**：鉴定师在线填写意见，多人会签取中位数为参考价，争议标记上会
6. **数据看板**：成交率与溢价率统计，网络现场价差分析，佣金自动核算

## 3. 核心流程

拍品全生命周期：送拍 → 鉴定估值 → 拍照 → 编辑排版 → 预展 → 出价 → 落槌 → 结算 → 提货

```mermaid

    "委托人送拍" --> "鉴定估值"
    "鉴定估值" --> "会签通过?"
    "会签通过?" -->|"是"| "拍照存档"
    "会签通过?" -->|"争议"| "上会审议"
    "上会审议" --> "拍照存档"
    "拍照存档" --> "编辑排版"
    "编辑排版" --> "图录生成"
    "图录生成" --> "预展"
    "预展" --> "拍卖会出价"
    "拍卖会出价" --> "落槌?"
    "落槌?" -->|"成交"| "生成结算单"
    "落槌?" -->|"流拍"| "退还保证金"
    "生成结算单" --> "买家付款"
    "买家付款" --> "卖家结算"
    "卖家结算" --> "提货出库"
    "退还保证金" --> "拍品退回"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨金配色——#1a1a2e（深墨蓝）为主背景色，#c9a96e（古铜金）为强调色，#f5f0e8（宣纸白）为卡片背景
- **次色调**：#8b6914（暗金）、#e8d5b7（浅驼）、#2d2d44（灰蓝）
- **按钮风格**：圆角4px，金边描边按钮为主操作，填充按钮为强调操作
- **字体**：标题用 Noto Serif SC（宋体气质），正文用 Noto Sans SC，数字用 DIN Alternate
- **布局**：顶部固定导航+侧边筛选面板+右侧内容区，卡片网格布局
- **图标**：Bootstrap Icons，线性风格
- **特效**：落槌成交时粒子撒花动画，加价按钮按压弹性动画，状态变更渐变过渡

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 登录表单 | 居中卡片式表单，古铜金边框，毛笔书法风格标题 |
| 首页仪表盘 | 数据概览 | 四宫格KPI卡片，趋势折线图，饼图品类分布 |
| 拍品列表 | 筛选面板 | 左侧折叠式筛选树（品类/朝代/状态/拍卖会），右侧3列卡片网格 |
| 拍品列表 | 卡片网格 | 缩略图+编号+名称+参考价+状态标签（彩色圆角标签） |
| 拍品详情 | 生命周期时间线 | 垂直时间线，节点带图标与时间戳，当前节点高亮 |
| 拍卖会详情 | 出价面板 | 左侧大图轮播+出价按钮组+当前价，右侧排行榜+倒计时圆环 |
| 图录编辑 | 拖拽排序 | 左侧可拖拽缩略图列表，右侧PDF分页预览 |
| 数据看板 | 统计图表 | 多标签页：成交分析/价差分析/佣金核算 |

### 4.3 响应式适配

- 桌面端优先（1440px+），适配平板（768px-1024px）和手机（<768px）
- 卡片网格：桌面3列 → 平板2列 → 手机1列
- 筛选面板：桌面侧边固定 → 移动端抽屉式弹出
- 出价面板：桌面左右分栏 → 移动端上下堆叠

### 4.4 交互特效

- 加价按钮：按下时缩放0.95 + 弹性回弹动画
- 落槌成交：全屏粒子撒花特效（金色圆点+碎纸片）
- 状态标签：变更时渐变过渡 + 短暂发光效果
- 出价更新：数字翻牌器动画
- 倒计时：圆环进度条 + 最后10秒红色闪烁
