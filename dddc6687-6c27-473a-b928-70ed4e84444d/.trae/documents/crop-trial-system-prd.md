# 农作物品种区域试验管理系统 - 产品需求文档（PRD）

## 1. 产品概述

本系统面向区域农作物品种试验管理中心，统筹辖区内12个试验站点的新品种区域试验数据。系统解决各站点 Excel 独立记录、汇总靠邮件催收合并、品种比较靠手工制表绘图、稳定性系数需逐品种 SPSS 计算、审定报告 Word 模板逐字段填写的痛点，将原长达两个月的"数据孤岛—手工汇总—逐项制表—报告填写"流程压缩至分钟级，支撑品审委员会15名专家高效出具审定意见。

- **目标用户**：试验站点技术人员（田间数据录入）、区域中心汇总员（多点分析与图表）、品审委员会专家（查阅报告与填写审定意见）
- **核心价值**：以 localStorage 持久化、统计引擎、Chart.js 可视化、jsPDF/SheetJS 导出构建"录入—汇总—分析—图表—报告"一体化闭环，消除数据孤岛与手工低效环节，支持3年数据共存

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|---------------------|------------------|
| 试验站点技术人员 | 田间数据录入页多步表单录入物候、农艺、抗性数据；Excel批量导入 | 录入与编辑本站点试验记录、查看校验异常 |
| 区域中心汇总员 | 多点汇总分析、GGE双标图、品种比较图表、报告生成 | 全部站点数据汇总分析、图表渲染、报告导出 |
| 品审委员会专家 | 审定报告页查阅品种摘要与稳定性评价 | 查阅报告、填写审定意见、导出PDF |

### 2.2 功能模块

1. **工作台总览（Dashboard）**：试验概况统计卡片、作物分布、年度进度、异常数据预警、快速入口
2. **试验方案配置（Trials）**：按作物设定参试品种、对照品种、站点分配、重复次数，支持年度复用与版本对比
3. **田间数据录入（Data Entry）**：分站点分品种多步向导，物候期自动算生育天数，农艺性状数值范围校验，抗性等级下拉，Excel批量导入
4. **多点汇总分析（Analysis）**：按品种汇总12站点产量，计算均值、变异系数、Shukla稳定性方差，生成稳定性排序表
5. **GGE双标图（GGE Biplot）**：基于品种×环境互作矩阵PCA分解，绘制双标图标识理想品种与代表性环境
6. **品种比较图表（Compare）**：产量柱状图、折线图、雷达图多维对比，自定义品种组与站点筛选
7. **审定报告生成（Reports）**：按品种自动填充产量摘要、稳定性评价、适应区域建议，导出PDF与Excel
8. **数据校验异常标注（Validation）**：检测缺失小区、极端值、逻辑矛盾，异常数据红色标记提示修正

## 3. 核心流程

**主流程一：数据录入与校验**
试验站点技术人员在工作台选择年度与作物 → 进入田间数据录入页 → 选择站点与品种 → 多步向导依次填写物候期(播期/出苗/抽穗/成熟) → 系统自动计算生育天数 → 填写12项农艺性状(实时数值范围校验) → 填写抗性等级(倒伏性/病害等级下拉) → 提交保存至 localStorage → 系统自动跑数据校验，缺失小区/极端值/逻辑矛盾标红提示 → 修正后数据进入可用池

**主流程二：多点汇总与品种比较**
汇总员在工作台选择年度 → 进入多点汇总分析页 → 筛选作物与品种组 → 统计引擎跨12站点汇总产量 → 计算均值、变异系数(2秒内)、Shukla稳定性方差 → 生成稳定性排序表 → 切换至品种比较图表页 → 选择柱状图/折线图/雷达图 → 自定义品种组与站点筛选 → 图表实时渲染(1秒内) → 切换至GGE双标图页 → PCA分解品种×环境矩阵(5秒内) → 双标图标识理想品种

**主流程三：审定报告生成**
汇总员/专家进入审定报告页 → 选择目标品种 → 系统自动填充产量摘要(均值/变异系数)、稳定性评价(Shukla方差分级)、适应区域建议(基于站点表现) → 预览PDF → 填写审定意见 → 一键导出PDF(8秒内)与Excel汇总表

## 4. 用户界面设计

### 4.1 设计风格

**美学方向：田野研究 · 精密数据（Field Research · Precision Data）**
打造一种介于现代数据分析平台与精密科研仪器之间的气质——既呼应农业研究的田野与丰收意象，又具备科研工具的严谨与精密。

- **主色调**：深植物绿 `#1f3d22`（深森林，代表生长）作为主品牌色；丰收金 `#c8902f`（成熟谷物）作为强调色；陶土棕 `#8b4513` 作为次级强调（土地意象）
- **背景**：暖奶油白 `#faf7f0`（主背景）+ 纯白卡片 `#ffffff`（带微妙暖色阴影），营造科研纸张的温润质感
- **辅助色**：深石板灰 `#3d4a3a`（文字）、柔和鼠尾草绿 `#7a9266`（次要元素）、警示砖红 `#b5402f`（异常标注）
- **按钮风格**：圆角(6px)实心按钮，主按钮深绿底白字带微妙下沉阴影；次要按钮描边样式；强调按钮丰收金
- **字体**：标题用 Fraunces（当代衬线，富有农业编辑气质）；正文用 Spline Sans（清晰现代）；数据/数字用 IBM Plex Mono（表格等宽对齐）
- **布局**：顶部导航栏 + 侧边栏功能菜单树 + 主区域卡片网格，信息密度高但层次分明
- **图标/emoji**：使用 Bootstrap Icons 线性图标，克制使用，呼应科研工具风格

### 4.3 响应式设计

- **桌面优先**：≥992px 完整双栏/三栏布局，侧边栏常驻
- **平板**：768-991px 侧边栏可折叠，图表区单列
- **移动端**：<768px 侧边栏折叠为汉堡菜单，表格横向滚动，卡片单列堆叠，录入向导纵向展开
- **触控优化**：按钮最小44×44px，下拉与选择器适配触控，图表 tooltip 适配长按

不适用（本系统为数据管理与分析工具，不涉及3D场景）
