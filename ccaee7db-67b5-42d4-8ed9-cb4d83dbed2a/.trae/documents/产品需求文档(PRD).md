## 一、项目概述

### 1.1 项目背景

随着广播电视行业的数字化、网络化、智能化转型，省级广电网络公司面临着覆盖范围广、设备数量多、运维难度大的挑战。为保障广播电视节目安全播出、提升运维管理效率、降低故障响应时间，亟需建设一套统一的省级广电网络播出监控系统。

### 1.2 项目规模

本系统覆盖全省 **16个地市**，管理 **120个机房**，监控 **8500个光节点**，实现从省级中心到地市分公司、区县机房、光节点的四级联动监控体系。

### 1.3 项目目标

- **安全播出保障**：7×24小时不间断监控播出信号质量，故障响应时间缩短至分钟级
- **运维效率提升**：通过智能告警聚合和自动化派单，运维效率提升60%以上
- **决策数据支撑**：提供多维度数据统计和趋势分析，为管理决策提供数据依据
- **资源统一管理**：实现机房设备、人员、流程的统一管理和可视化展示

### 1.4 项目范围

| 范围分类 | 包含内容 |
|---------|--------|
| 监控对象 | 编码器、复用器、调制器、光发射机、光接收机、OLT、ONU等设备 |
| 监控指标 | 信号强度、信噪比、误码率、带宽利用率、设备温度、电压等 |
| 地理范围 | 全省16个地市、120个机房、8500个光节点 |
| 功能范围 | 实时监控、告警管理、数据分析、排班管理、机房管理、应急指挥 |

## 二、用户画像

### 2.1 7×24值班员

#### 基本信息
- **角色名称**：监控中心值班员
- **人员数量**：约40人（四班三运转）
- **工作地点**：省级监控中心大厅
- **使用设备**：多屏工作站（4-6块显示屏）

#### 用户特征
- 年龄：25-40岁
- 学历：大专及以上，通信/电子相关专业
- 计算机水平：中等，熟练操作办公软件和专业监控系统
- 工作经验：1年以上广电运维或监控相关经验

#### 核心诉求
1. **实时掌握全局状态**：一眼看清全网播出状况，快速发现异常
2. **告警快速处理**：告警信息不遗漏、不重复，处理流程清晰
3. **操作简便高效**：常用操作一键可达，减少操作步骤
4. **信息展示清晰**：大屏监控画面清晰，关键指标醒目

#### 典型场景
- **场景1**：凌晨3点值班时，某地市光节点告警频发，需要快速定位影响范围并通知运维人员
- **场景2**：交接班时，需要清晰展示本班次告警处理情况和未完成事项
- **场景3**：重要保障期（如春晚、重大赛事），需要重点监控关键链路信号质量

#### 使用频率
- 高频用户，每班8小时持续使用
- 日均操作次数：200-500次

## 三、核心功能需求

### 3.1 多画面监控墙

#### 功能概述
多画面监控墙是系统的核心展示界面，为值班员提供全网运行状态的实时可视化监控。支持大屏拼接显示，最多可同时展示64路监控画面。

#### 功能模块

##### 3.1.1 画面布局管理
- 支持多种预设布局：1画面、4画面、9画面、16画面、25画面、36画面、64画面
- 支持自定义布局：用户可拖拽调整画面大小和位置
- 支持布局模板保存：将常用布局保存为模板，一键切换
- 支持布局轮巡：多个布局按设定时间间隔自动切换

##### 3.1.2 监控画面内容
- **视频信号监控**：解码显示播出频道实时画面，支持SDI/IP/HLS等多种信号源
- **设备状态监控**：以卡片形式展示设备运行参数（信号电平、MER、BER、温度等）
- **拓扑链路监控**：图形化展示信号传输链路，链路状态实时着色
- **机房动环监控**：温度、湿度、供电、门禁等环境参数展示
- **地图分布监控**：基于GIS地图展示全省机房和光节点地理分布及状态

##### 3.1.3 画面交互操作
- 单画面双击放大/还原
- 画面拖拽排序
- 右键快捷菜单：查看详情、告警历史、远程控制、截图录像
- 实时截图和定时截图功能
- 关键画面录像存储（告警触发录像+手动录像）

##### 3.1.4 多屏适配
- 支持1-8块物理屏拼接显示
- 画面可跨屏拖拽
- 支持画面墙与操作面板分屏显示

| 单屏最大画面数 | 64路 |
| 视频延迟 | < 500ms |
| 画面切换响应 | < 200ms |
| 数据刷新频率 | 实时推送/秒级刷新 |

### 3.2 智能告警聚合

#### 功能概述
通过智能算法对海量告警信息进行去重、压缩、关联和分级，避免告警风暴，确保值班员聚焦重要告警，提升处理效率。

#### 功能模块

##### 3.2.1 告警分级管理
- **紧急告警（红色）**：影响播出的重大故障，如主路信号中断、核心设备宕机等，需立即处理
- **重要告警（橙色）**：影响服务质量但未中断播出的故障，如备路异常、指标超标等，15分钟内处理
- **一般告警（黄色）**：不影响当前播出但需关注的异常，如设备温度偏高、备用通道异常等，2小时内处理
- **提示告警（蓝色）**：日常运行提示信息，如设备巡检提醒、阈值接近等，按计划处理

##### 3.2.2 告警去重与关联
- **重复告警压制**：同一设备同一告警在设定时间窗口内只展示一次，记录重复次数
- **根源告警分析**：基于拓扑关系和告警关联规则，自动识别根源告警，标注衍生告警
- **时间窗口聚合**：5分钟窗口内同机房/同链路的同类告警自动合并展示
- **告警抑制规则**：上级设备告警时，自动抑制下级关联设备的告警（可配置）

##### 3.2.3 告警通知推送
- **站内通知**：系统内消息弹窗、声音提醒、顶部横幅
- **语音播报**：TTS语音播报紧急告警内容
- **短信通知**：紧急告警自动发送短信至值班人员和运维负责人
- **电话通知**：特别重大故障自动拨打值班电话
- **移动端推送**：App推送、企业微信/钉钉消息推送

##### 3.2.4 告警处理流程
- 告警确认：值班员确认收到告警，状态从"未处理"变为"处理中"
- 告警派单：一键生成工单，指派运维人员处理
- 处理记录：记录处理过程、处理人、处理时间、处理结果
- 告警关闭：故障修复后验证关闭，或标记为误报
- 告警升级：超时未处理的告警自动升级通知上级

##### 3.2.5 告警配置管理
- 告警阈值配置：各指标的告警阈值可按设备类型、重要性分级配置
- 告警规则配置：自定义告警关联规则、抑制规则、升级规则
- 通知策略配置：不同级别告警的通知方式、通知人员、通知时段可配置
- 屏蔽时段配置：支持配置设备维护窗口，期间自动屏蔽告警

#### 验收标准
| 指标 | 要求 |
|-----|------|
| 告警处理效率提升 | ≥ 60% |
| 重复告警压缩率 | ≥ 80% |
| 紧急告警通知延迟 | < 30秒 |
| 日均告警条目（聚合后） | ≤ 500条 |

### 3.3 历史趋势分析

#### 功能概述
对设备运行历史数据进行多维度存储、统计、分析和可视化展示，帮助运维团队发现潜在隐患、优化资源配置、支撑管理决策。

#### 功能模块

##### 3.3.1 数据存储与查询
- **原始数据存储**：秒级采集数据保留30天，分钟级聚合数据保留1年，小时级聚合数据永久保留
- **多维度查询**：按时间范围、地域、机房、设备类型、指标类型等多维度组合查询
- **数据导出**：支持Excel、CSV、PDF格式导出查询结果
- **数据对比**：支持选择多个设备或同一设备不同时间段的数据进行对比分析

##### 3.3.2 趋势图表展示
- **基础折线图**：展示单个指标随时间变化趋势
- **多指标叠加图**：同一图表展示多个相关指标，便于关联分析
- **区域热力图**：按地域/机房展示指标分布热力
- **柱状对比图**：不同周期（日/周/月）数据对比
- **饼图/环形图**：告警类型分布、故障原因分布等占比分析
- **散点分布图**：异常数据点分布识别

##### 3.3.3 统计报表
- **日报**：每日告警汇总、故障处理情况、关键指标均值/峰值
- **周报**：本周运行态势、同比环比分析、TOP10故障机房/设备
- **月报**：月度运维KPI、资源利用率、SLA达成情况
- **季报/年报**：季度/年度总结报告，含趋势预测和建议
- **自定义报表**：用户可自定义报表模板和统计维度

##### 3.3.4 异常检测与预测
- **阈值基线学习**：基于历史数据自动学习指标正常基线范围
- **异常模式识别**：识别突增、突降、波动异常等典型异常模式
- **趋势预测**：基于ARIMA/LSTM等算法预测关键指标未来走势
- **故障预警**：根据趋势预测提前发出潜在故障预警

##### 3.3.5 大屏数据看板
- 全省运行总览大屏：核心指标实时滚动展示
- 分公司运维KPI看板：各分公司关键指标排名和对比
- 安全播出统计看板：安全播出时长、中断次数、MTBF/MTTR统计
- 自定义看板：支持用户拖拽组建个人工作台

#### 验收标准
| 指标 | 要求 |
|-----|------|
| 最大数据点展示 | 单图≥10万数据点 |
| 图表加载时间 | < 3秒 |
| 报表生成时间 | < 10秒 |
| 数据查询响应 | < 2秒 |

### 3.4 值班排班管理

#### 功能概述
实现监控中心值班人员的排班、考勤、交接、考核的全流程管理，确保7×24值班制度规范执行。

#### 功能模块

##### 3.4.1 排班计划管理
- **班次配置**：支持多种班次模式（如8小时三班制、12小时两班制、弹性班次等）
- **排班日历**：按月度/周度日历视图展示排班计划，支持拖拽调整
- **自动排班**：根据人员配置、班次规则、节假日设置自动生成排班建议
- **排班冲突检测**：自动检测人员排班冲突、连续上班超时、法定休假冲突等
- **调班申请**：值班员在线提交调班申请，审批流程电子化
- **节假日排班**：特殊日期独立排班规则设置

##### 3.4.2 值班考勤管理
- **打卡签到**：支持账号登录签到、指纹/人脸签到、IP白名单签到
- **迟到/早退/缺勤**：系统自动记录考勤异常
- **请假管理**：支持年假、事假、病假等多种假期类型，在线申请审批
- **加班统计**：自动统计加班时长和调休余额
- **考勤报表**：月度考勤汇总、异常明细、出勤统计

##### 3.4.3 交接班管理
- **交接班记录**：标准化交接班电子表单，包含：
  - 本班次告警处理汇总
  - 未完成事项和跟进要求
  - 设备变更和维护记录
  - 上级指示和重要事项
- **一键交班**：交班人提交记录，接班人确认后交接完成
- **交接班提醒**：到点提醒当班人员准备交接
- **历史追溯**：所有交接班记录永久保存，可按时间/人员查询

##### 3.4.4 值班日志
- **操作日志**：自动记录值班员系统操作（告警确认、派单、配置变更等）
- **人工记事**：值班员手动记录重要事件、电话记录、来访登记等
- **日志关联**：告警、工单、操作自动关联到对应班次日志
- **日志审计**：管理员可审计所有值班日志

##### 3.4.5 绩效考核
- **KPI配置**：值班员考核指标配置（告警及时响应率、工单派发准确率、交接班规范等）
- **自动评分**：系统根据数据自动计算KPI得分
- **人工评份**：主管人工评分模块
- **考核报表**：月度/季度/年度考核排名和统计

### 3.5 机房态势下钻

#### 功能概述
从全省宏观视图逐层下钻到地市、区县、机房、机架、设备、端口的明细信息，实现管理颗粒度的灵活切换。

#### 功能模块

##### 3.5.1 多层级导航视图
- **L1-全省总览**：GIS地图展示16地市分布，各地市状态着色（正常/告警/离线），显示关键汇总指标
- **L2-地市视图**：展示地市下各区县机房分布，机房状态和设备统计
- **L3-机房视图**：机房3D/2D平面图，展示机架布局、设备位置、动环参数
- **L4-机架视图**：机架正视图，U位展示，设备安装位置和运行状态
- **L5-设备视图**：设备面板图，端口状态、指示灯、详细运行参数
- **L6-端口视图**：端口详细配置、链路信息、性能指标、历史数据

##### 3.5.2 GIS地图功能
- **地图图层**：行政区划图层、机房图层、光节点图层、光缆路由图层
- **状态渲染**：按设备状态自动着色（绿色正常/黄色告警/橙色重要/红色紧急/灰色离线）
- **空间查询**：框选、圈选、多边形选择区域内的设备
- **路径分析**：两点间光缆路由查询、最佳抢修路径规划

### 4.5 动画效果

#### 动画设计原则
- **目的性**：每个动画都有明确的目的（反馈、引导、过渡、情绪）
- **适度性**：动画时长控制在 200ms-500ms，不影响操作效率
- **自然性**：使用符合物理直觉的缓动函数
- **可关闭**：提供开关选项，用户可选择关闭动效

#### 动画分类与规范

##### 4.5.1 页面过渡动画
- **路由切换**：页面淡入淡出 300ms ease-out，新页面从下方向上偏移 8px
- **模态框**：背景遮罩淡入 200ms，弹窗从中心缩放 0.95→1 + 淡入 250ms cubic-bezier(0.4, 0, 0.2, 1)
- **抽屉面板**：左侧滑入 300ms cubic-bezier(0.4, 0, 0.2, 1)，遮罩同步淡入
- **下拉菜单**：下拉展开 200ms ease-out，菜单项逐个淡入+下移 20ms 错开

##### 4.5.2 数据更新动画
- **数值滚动**：数据变化时从旧值滚动到新值，时长 800ms
- **高亮闪烁**：新产生的告警行高亮闪烁 2 秒后恢复
- **状态切换**：状态色块颜色渐变过渡 500ms
- **图表更新**：ECharts dataZoom 平滑过渡，数据点增量更新动画

##### 4.5.3 交互反馈动画
- **按钮**：悬停放大 1.02 150ms，点击缩放 0.98 100ms
- **卡片**：悬停上移 2px + 阴影加深 200ms
- **输入框**：聚焦时边框高亮扩散 200ms
- **开关**：滑块滑动 200ms cubic-bezier(0.4, 0, 0.2, 1)

##### 4.5.4 告警动效
- **紧急告警弹窗**：屏幕边缘红色脉冲闪烁 + 抖动 + 声音提醒
- **顶部横幅告警**：从顶部滑入 300ms，常驻直到确认
- **告警声音**：
  - 紧急：急促高音，间隔2秒重复
  - 重要：中等音调，间隔5秒重复
  - 一般：柔和提示音，单次

##### 4.5.5 加载动画
- **首屏加载**：系统Logo + 进度条 + 加载提示文案（随机切换有趣提示）
- **骨架屏**：数据加载前显示骨架占位图，宽度渐变闪烁
- **局部加载**：按钮/卡片内小转圈加载器
- **全屏加载**：半透明遮罩 + 居中加载动画

### 6.5 技术选型约束

1. **禁止使用**：jQuery、Vue（本项目统一技术栈为React）、废弃或停止维护的开源库
2. **组件库一致性**：优先使用Ant Design组件，不得混用多种UI组件库
3. **状态管理一致性**：全局状态统一使用Zustand，禁止引入Redux、MobX等其他状态库
4. **工具库最小化**：避免引入功能重叠的库（如lodash和lodash-es只选其一）
5. **包体积管控**：构建产物单chunk < 500KB，首屏资源总计 < 2MB（gzip后），引入新库需做体积评估
6. **源码可读**：核心业务逻辑禁止使用代码混淆和加密，便于后续维护
