## 1. 产品概述

职业技能鉴定管理系统是为区域职业技能鉴定指导中心打造的全流程数字化管理平台，解决当前手工操作效率低、差错率高、资源调配难等痛点，覆盖考期申报、智能组卷、考场排程、考评员派遣、成绩管理、电子证书全业务链条。

- **核心目标**：实现鉴定业务全流程数字化，将8人编制团队的年处理能力从1200场次、3.6万人次提升50%以上，人工操作差错率降低90%
- **目标用户**：中心管理员（8人）、认定机构联络员（45人）、考评员（180人）、考生（3.6万人/年）
- **市场价值**：提升区域职业技能鉴定工作的规范化、标准化水平，为全国同类机构提供可复制的数字化解决方案

## 2. 核心功能

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 中心管理员 | 系统预置账号 | 考期审批、全局调度、题库管理、统计分析、证书核发 |

5. **证书管理**：电子证书生成、二维码验真、证书查询、下载打印
6. **统计看板**：多维度统计报表、图表可视化、数据导出

## 3. 核心流程

### 3.1 考期申报与执行流程

认定机构提交考期申请 → 系统自动检测冲突（考场、考评员、资格） → 推荐可调剂时段 → 中心管理员审批 → 匹配考场工位与考评员 → 考生自助报名缴费 → 系统自适应组卷（A/B卷） → 考试执行 → 考评员录入成绩 → 系统校验与公示 → 生成电子证书 → 考生下载/扫码验真

```mermaid
flowchart LR
    A["认定机构提交考期"] --> B["冲突检测<br/>考场/考评员/资格"]
    B --> C{有冲突?}
    C -->|是| D["推荐调剂时段"]
    D --> E["机构确认调整"]
    E --> B
    C -->|否| F["中心管理员审批"]
    F --> G["匹配考场与考评员"]
    G --> H["考生报名缴费"]
    H --> I["自适应组卷引擎"]
    I --> J["考试执行"]
    J --> K["考评员录入成绩"]
    K --> L["系统校验与公示"]
    L --> M["生成电子证书"]
    M --> N["考生下载/扫码验真"]
```

### 3.2 考生自助服务流程

考生注册 → 选择工种等级 → 查看可报考期 → 在线缴费 → 打印准考证 → 查看考场信息 → 考试 → 查询成绩 → 下载电子证书

## 4. 用户界面设计

### 4.1 设计风格

**设计定位**：政务专业、稳重可信、高效实用

- **主色调**：政务蓝 `#165DFF`，代表专业与权威
- **辅助色**：成功绿 `#00B42A`、警告黄 `#FF7D00`、危险红 `#F53F3F`、信息灰 `#86909C`
- **按钮风格**：圆角4px，悬停微阴影，点击反馈，主按钮蓝色填充，次按钮边框样式
- **字体**：系统无衬线字体（-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"），标题16-20px粗体，正文14px常规
- **布局风格**：顶部导航栏 + 左侧菜单（部分页面） + 内容区卡片式布局，信息密度适中
- **图标风格**：Bootstrap Icons线性图标，简洁统一

### 4.3 响应式设计

- **桌面端**（≥1200px）：完整导航，多列布局，表格完整展示
- **平板端**（768px-1199px）：导航简化，两列布局，表格横向滚动
- **移动端**（<768px）：汉堡菜单，单列堆叠，卡片化展示，关键信息优先

**移动端优化**：
- 日历视图简化为列表视图
- 表格自动转卡片列表
- 按钮尺寸增大至44px×44px便于触控
- 表单输入框适配软键盘弹出

### 4.4 交互与动效

- **页面加载**：顶部进度条，内容区淡入
- **卡片悬停**：上移2px，阴影加深，过渡0.2s
- **按钮点击**：缩放0.98，背景色加深
- **模态框**：缩放进入，背景遮罩淡入
- **表单校验**：错误信息滑入，输入框红色边框抖动
- **日历拖拽**：半透明预览，释放后弹性定位
