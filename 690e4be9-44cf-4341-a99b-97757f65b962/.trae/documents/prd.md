## 1. 产品概述

市级公共交通智能排班与运营调度系统，面向58条公交线路、1260辆运营车辆及3200余名司乘人员，解决手工排班低效、运力与客流失配、异常响应滞后等核心痛点。系统通过遗传算法自动生成行车计划、实时GPS融合到站预测、动态运力调整与客流分析，实现公交运营从"经验驱动"向"数据驱动"转型，目标降低高峰滞站率40%以上、冷门线路空驶率30%以上。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 调度主任 | 管理员分配账号 | 审核排班计划、处置重大运营异常、查看全局报表 |
| 线路调度员 | 管理员分配账号 | 编制与调整排班、监控车辆实时位置与到站预测、确认运力调整方案 |
| 车队长 | 管理员分配账号 | 司机考勤与替班管理、维保信息录入、查看所属线路运营状态 |
| 数据分析师 | 管理员分配账号 | 客流分布查询、运营效率报表、导出PDF/Excel |

### 2.2 功能模块

1. **调度看板页面**：线路地图实时展示、车辆GPS图标与满载率颜色渐变、到站预测倒计时、异常告警弹窗
2. **排班编辑器页面**：甘特图时间轴编排、拖拽调整班次、约束冲突告警、审核流转
3. **司机排班页面**：月度轮班表编制、请假替班匹配、调班建议生成
4. **客流分析页面**：OD客流热力图、断面满载率、运力缺口排行、时段对比
5. **维保管理页面**：里程阈值保养标记、故障抛锚紧急替代方案
6. **运营日报页面**：日客运量、准点率、里程利用率汇总、PDF/Excel导出

## 3. 核心流程

### 3.1 智能排班生成流程

调度员选择线路与日期，系统读取线路参数（里程、首末班时间、配车数）与司机约束（工时上限、休息间隔），遗传算法引擎在15秒内生成日行车计划，调度员在甘特图中微调后提交审核，调度主任审核通过后写入数据库并下发车载终端。

```mermaid
flowchart TD
    "调度员选择线路与日期" --> "系统读取线路参数与司机约束"
    "系统读取线路参数与司机约束" --> "遗传算法引擎生成日行车计划"
    "遗传算法引擎生成日行车计划" --> "调度员在甘特图中微调"
    "调度员在甘特图中微调" --> "提交审核"
    "提交审核" --> "调度主任审核"
    "调度主任审核" -->|通过| "写入数据库并下发车载终端"
    "调度主任审核" -->|驳回| "调度员修改"
    "调度员修改" --> "提交审核"
```

### 3.2 实时运力调整流程

系统持续检测GPS数据与客流数据，当连续3个班次满载率超90%或晚点超5分钟时，自动生成加密班次推荐方案并推送给调度员，调度员一键确认后系统自动调整后续排班并下发。

```mermaid

    "GPS与客流数据实时监测" --> "异常检测引擎"
    "异常检测引擎" -->|满载率>90%连续3班| "生成加密班次推荐方案"
    "异常检测引擎" -->|晚点>5分钟| "生成加密班次推荐方案"
    "生成加密班次推荐方案" --> "推送调度员确认"
    "推送调度员确认" -->|确认| "自动调整排班并下发"
    "推送调度员确认" -->|忽略| "记录决策日志"
```

### 3.3 车辆故障应急流程

车辆抛锚触发故障上报，系统标记车辆不可排班，自动搜索附近可用备用车辆，生成紧急替代方案含班次临时调整，推送车队长与调度员。

    "标记车辆不可排班" --> "搜索附近可用备用车辆"
    "搜索附近可用备用车辆" --> "生成紧急替代方案"
    "生成紧急替代方案" --> "推送车队长与调度员确认"

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰（#1B2A4A）作为导航与侧栏底色，体现专业调度系统权威感
- **辅色调**：活力橙（#FF6B35）用于告警与关键操作按钮，冷灰蓝（#4A90D9）用于数据与链接
- **状态色**：绿色（#22C55E）→ 黄色（#F59E0B）→ 红色（#EF4444）渐变表示满载率从低到高
- **按钮风格**：圆角8px，次要按钮描边风格，主要按钮实心填充
- **字体**：标题使用 DIN Alternate（数字显示），正文使用 PingFang SC / Microsoft YaHei
- **布局风格**：左侧固定导航栏 + 主区域地图/数据看板，顶部状态栏
- **图标风格**：线性图标，2px描边，配合 Element Plus 图标体系

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|

### 4.3 响应式适配

- 桌面优先设计，主要适配1920px与1366px两种调度台分辨率
- 地图区域最小宽度960px不可缩小
- 1366px下侧栏自动折叠为图标模式
- 排班编辑器甘特图支持水平滚动
- 客流分析热力图支持缩放查看

### 4.4 性能约束

- 调度看板首屏加载不超2秒
- GPS位置推送延迟不超3秒
- 排班引擎求解58条线路日计划不超15秒
- 单线路历史客流查询响应不超500毫秒
- 支持200个调度终端同时在线
- GraphQL单次查询深度限制4层
- REST接口分页查询不超200条每页
