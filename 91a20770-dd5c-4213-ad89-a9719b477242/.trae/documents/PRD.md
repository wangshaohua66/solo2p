# 明视眼镜连锁门店运营管理系统 — 产品需求文档（PRD）

## 1. 产品概述

本系统面向某区域连锁眼镜零售集团（12 家门店、36 名验光师、年接待顾客 15 万人次）研发，将分散在纸质档案与 12 套 Excel 中的业务数据统一电子化，实现验光数据电子化、库存实时共享、加工流程追踪、技师智能排班与会员营销管理的一体化运营。

- **目标用户**：门店店长、验光师、加工技师、收银员、集团运营管理人员
- **核心价值**：跨门店实时协同，消除电话调货与人工核算错漏，顾客扫码查单提升体验，数据驱动经营决策

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 集团运营 | 全局数据查看、跨店调拨审批、报表分析 | 所有门店数据只读 + 调拨审批 |
| 门店店长 | 本店排班、库存、订单、会员管理 | 本店全部功能读写 |
| 验光师 | 录入验光数据、查询历史处方 | 验光模块读写 |
| 加工技师 | 接单、加工、质检、交付状态更新 | 加工模块读写 |
| 收银员 | 结账、积分累计、促销匹配 | 会员与收银读写 |

### 2.2 功能模块

1. **工作台首页**：今日待办、关键指标卡片、库存预警、系统通知
2. **验光管理**：验光记录列表、新增验光表单、历史处方对比、配镜建议
3. **库存管理**：镜架/镜片库存列表、入库出库、门店调拨、预警提醒
4. **加工追踪**：订单列表、加工状态流转、扫码查进度、超时提醒
5. **排班管理**：技师名单、周排班拖拽、违规预警、工时绩效统计
6. **会员营销**：会员档案、积分管理、促销活动配置、最优优惠匹配
7. **数据报表**：客流量/验光量/配镜量/销售额统计、横向对比、同环比

## 3. 核心流程

### 3.1 顾客到店配镜全流程
顾客到店 → 视力检查与验光建档（验光模块）→ 选择镜架镜片（库存模块扣减）→ 生成加工订单（加工模块）→ 接单→镜片加工→镜架调整→质检→交付 → 结账累计积分（会员模块）。

### 3.2 跨门店调拨流程
门店 A 发现缺货 → 查询全网库存 → 发起调拨申请 → 门店 B 确认 → 出库扣减 A / 入库增加 B → 订单继续加工。

### 3.3 技师排班流程
店长打开周排班 → 拖拽技师到班次 → 系统检测连续工作超 6 天或日均超 8 小时 → 预警标红 → 调整 → 发布排班。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：眼科诊所专业蓝绿色系（`#0d6e6e` 深青、`#14b8a6` 青绿、`#5eead4` 浅青）
- **辅助色**：`#f0fdfa` 极浅青背景、`#fbbf24` 警示橙、`#ef4444` 危险红、`#3b82f6` 信息蓝
- **按钮风格**：圆角 6px，主按钮深青底白字、次按钮描边、危险按钮红色
- **字体**：Noto Sans SC（正文）、Noto Serif SC（标题强调）
- **布局**：三栏栅格，左侧固定导航 220px、中间自适应主内容、右侧快捷面板 320px
- **图标**：Bootstrap Icons，状态用彩色徽章
- **表格**：隔行变色（`#f0fdfa`）、悬停高亮、状态变更过渡动画 0.2s

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 工作台 | 指标卡 | 5 列卡片、图标+数字+趋势箭头、悬停上浮 |
| 验光管理 | 处方对比 | 双列并排卡片 + 左侧时间轴 |
| 库存管理 | 库存列表 | 表格 + 数量徽章 + 预警红色标签 |
| 加工追踪 | 进度条 | 五段式进度条、当前节点脉冲动画 |
| 排班管理 | 排班表 | 日历网格、拖拽阴影、违规红色边框 |
| 数据报表 | 图表 | 折线/柱状/饼图、Tab 切换时间维度 |

### 4.3 响应式
- 桌面优先（≥1200px）：三栏完整布局
- 平板（768–1199px）：右侧面板折叠为顶部抽屉
- 移动端（<768px）：导航折叠为汉堡菜单，主内容单栏，快捷面板隐藏

### 4.4 性能约束
- 首屏加载 < 1.5 秒
- 路由切换 < 200 毫秒
- 单门店 localStorage < 8MB
- 1000 行表格滚动流畅不掉帧
- 拖拽排班延迟 < 100 毫秒
- 数据变更防抖保存避免频繁写入
