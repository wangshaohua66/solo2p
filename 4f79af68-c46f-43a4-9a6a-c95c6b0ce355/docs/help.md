# pavement CLI 使用帮助文档

## 概述

`pavement` 是国省干线路面病害检测与养护管理系统的命令行工具，用于：

- 批量导入路面检测CSV数据
- 依据JTGH20-2018标准进行病害等级智能判定
- 多条件组合查询路段信息
- 计算养护优先级并排序
- 制定预算分配方案
- 生成Markdown格式养护方案报告
- 进行多维度数据统计分析
- 批量清除历史数据

---

## 全局选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `-h, --help` | 显示帮助信息 | - |
| `-v, --version` | 显示版本号 | - |
| `--verbose` | 显示详细执行日志 | 关闭 |
| `--quiet` | 仅输出结果，不显示中间信息 | 关闭 |
| `--db <路径>` | 指定SQLite数据库文件路径 | `./pavement.db` |

**示例：**
```bash
pavement --db ./data/2024q1.db import -d ./csv
pavement --verbose stats --dim all
pavement --quiet query -r G108 --limit 100
```

## 子命令详解

### 1. `import` - 批量导入CSV检测文件

#### 功能描述
扫描指定目录下的所有CSV文件，自动识别列映射关系，清洗异常数据后批量入库。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `-d, --dir` | string | 是 | CSV文件所在目录路径 |
| `-b, --batch` | string | 否 | 指定批次号，不指定则自动生成 |
| `--details` | bool | 否 | 显示导入失败的详细记录 |

#### CSV文件格式要求
- 第一行为表头行，支持中英文列名自动识别
- 支持的必要列（任意一种命名即可）：
  - 路线编号：`route_id`, `RouteID`, `路线编号`, `路线`
  - 起始桩号：`start_station`, `起始桩号`, `起点桩号`
  - 终止桩号：`end_station`, `终止桩号`, `终点桩号`
  - IRI平整度：`iri`, `IRI`, `平整度`, `国际平整度指数`
  - 车辙深度：`rut_depth`, `RutDepth`, `车辙`, `车辙深度`
  - 裂缝密度：`crack_density`, `裂缝`, `裂缝密度`, `裂缝率`
- 可选列：
  - 路段长度：`section_length`, `length`, `路段长度`, `里程`
  - 交通流量：`traffic_volume`, `交通量`, `AADT`
  - 重要性权重：`importance`, `weight`, `重要性`
  - 养护中心：`maintenance_center`, `养护中心`, `管养单位`
  - 检测日期：`detect_date`, `date`, `检测日期`
  - 批次号：`batch_id`, `批次号`

#### 桩号格式
标准格式：`K数字+数字`，例如：
- `K100+000` → 100公里000米处
- `K123+456` → 123公里456米处

#### 返回值说明
- 扫描文件总数
- 成功/失败文件数
- 总记录数、成功记录数、失败记录数
- 导入成功率（百分比）
- 关联批次号列表
- 总耗时

#### 使用示例
```bash
# 基础导入
pavement import -d ./data/2024Q1

# 指定批次号导入
pavement import --dir ./data/2024Q1 --batch Q1-2024-DETECT

# 显示失败详情
pavement import -d ./data/2024Q1 --details --verbose

# 指定数据库文件导入
pavement --db ./production.db import -d ./data/2024Q1 -b Q1
```

### 2. `classify` - 病害等级智能判定

#### 功能描述
依据JTG H20-2018《公路技术状况评定标准》，对IRI平整度、车辙深度、裂缝密度三项指标分别计算分数，加权综合后判定优良中差四级病害等级。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `--all` | bool | 条件必填 | 对所有记录执行判定 |
| `--batch` | string | 条件必填 | 按批次号判定 |
| `-r, --route` | string | 条件必填 | 按路线编号判定 |
| `--iri-weight` | float64 | 否 | IRI指标权重 (0-1)，默认0.40 |
| `--rut-weight` | float64 | 否 | 车辙深度权重 (0-1)，默认0.30 |
| `--crack-weight` | float64 | 否 | 裂缝密度权重 (0-1)，默认0.30 |

> **注意**：`--all`、`--batch`、`--route` 三者必须指定其一

#### 判定算法

**单项指标评分阈值**（JTG H20-2018标准）：

| 分数 | IRI (m/km) | 车辙深度 (mm) | 裂缝密度 (%) |
|------|-----------|--------------|-------------|
| 100 | ≤1.5 | ≤5 | ≤1 |
| 90 | ≤2.0 | ≤8 | ≤3 |
| 80 | ≤2.5 | ≤10 | ≤5 |
| 70 | ≤3.0 | ≤12 | ≤8 |
| 60 | ≤3.5 | ≤15 | ≤10 |
| 50 | ≤4.5 | ≤20 | ≤15 |
| 40 | ≤6.0 | ≤25 | ≤20 |
| 30 | ≤8.0 | ≤30 | ≤25 |
| 20 | ≤10.0 | ≤35 | ≤30 |
| 10 | ≤12.0 | ≤40 | ≤35 |
| 0 | >12.0 | >40 | >35 |

**综合评定等级**：
- 总分 = IRI分 × 0.40 + 车辙分 × 0.30 + 裂缝分 × 0.30
- **优**：总分 ≥ 85
- **良**：70 ≤ 总分 < 85
- **中**：55 ≤ 总分 < 70
- **差**：总分 < 55

#### 返回值说明
- 判定总记录数、成功/失败数
- 数据库更新成功数
- 总耗时、单条平均耗时
- 病害等级分布统计（各级数量及占比）

#### 使用示例
```bash
# 全量判定
pavement classify --all

# 按批次号判定并调整权重
pavement classify --batch Q1-2024 --iri-weight 0.35 --rut-weight 0.35 --crack-weight 0.30

# 按路线编号判定
pavement classify -r G108 --verbose
```

### 3. `query` - 多条件组合查询路段

#### 功能描述
按路线编号、起止桩号范围、病害等级、检测日期范围等条件组合查询，输出符合条件的路段清单。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `-r, --route` | string | 否 | 路线编号（如G108、S305） |
| `-s, --start` | string | 否 | 起始桩号（如K100+000） |
| `-e, --end` | string | 否 | 终止桩号（如K150+000） |
| `-g, --grade` | string | 否 | 病害等级：优/A、良/B、中/C、差/D |
| `--from` | string | 否 | 起始日期 YYYY-MM-DD |
| `--to` | string | 否 | 终止日期 YYYY-MM-DD |
| `-l, --limit` | int | 否 | 最大返回记录数，默认500 |

#### 返回字段说明

| 字段 | 说明 |
|------|------|
| ID | 记录唯一标识 |
| 路线 | 路线编号 |
| 起止桩号 | 路段范围（如 K100+000 ~ K100+500） |
| 长度(km) | 路段长度（公里） |
| IRI | 国际平整度指数 (m/km) |
| 车辙(mm) | 车辙深度（毫米） |
| 裂缝(%) | 裂缝密度（百分比） |
| PCI | 综合评定分数 (0-100) |
| 等级 | 病害等级（优/良/中/差，带颜色高亮） |
| 检测日期 | YYYY-MM-DD格式 |
| 养护中心 | 管养单位名称 |

#### 使用示例
```bash
# 查询某路线所有差等路段
pavement query -r G108 -g 差

# 查询某路段范围内的记录
pavement query -r S305 -s K50+000 -e K80+000

# 按日期范围查询
pavement query --from 2024-01-01 --to 2024-03-31 --limit 1000

# 多条件组合查询
pavement query -r G107 -s K200+000 -e K300+000 -g 中 --from 2024-01-01 --quiet
```

### 4. `rank` - 养护优先级排序

#### 功能描述
综合考虑病害等级（50%权重）、交通流量（25%）、路段重要性（15%）、成本效益（10%）四项因素，计算各路段养护优先级评分，输出Top N高优先级路段。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 | 默认值 |
|------|------|------|------|--------|
| `-n, --top` | int | 否 | 返回Top N优先级路段 | 50 |
| `--grade-weight` | float64 | 否 | 病害等级权重 | 0.50 |
| `--traffic-weight` | float64 | 否 | 交通流量权重 | 0.25 |
| `--importance-weight` | float64 | 否 | 重要性权重 | 0.15 |
| `--cost-weight` | float64 | 否 | 成本效益权重 | 0.10 |

> **注意**：四项权重之和必须等于1.0

#### 优先级评分算法

1. **病害等级得分 (0-100)**：等级越差得分越高
   - 优：15分，良：35分，中：65分，差：95分

2. **交通流量得分 (0-100)**：AADT越大得分越高，上限50000辆/日

3. **重要性得分 (0-100)**：依据重要性权重（0.5-3.0）线性换算

4. **成本效益得分 (0-100)**：病害严重度×里程 / 预估成本，取对数归一化

5. **优先级总分** = 加权求和，保留2位小数

#### 优先级等级

| 优先级评分 | 描述 | 颜色标识 |
|-----------|------|----------|
| ≥ 85 | 极高优先级 | 红底白字 |
| 70 - 85 | 高优先级 | 红色 |
| 50 - 70 | 中等优先级 | 黄色 |
| 30 - 50 | 较低优先级 | 青色 |
| < 30 | 低优先级 | 绿色 |

#### 返回字段说明
- 排名、路线、起止桩号
- 路段长度、病害等级
- PCI评分、优先级评分
- 预估养护费用（元）
- 优先级描述

#### 使用示例
```bash
# 默认Top 50
pavement rank

# 自定义Top 100
pavement rank --top 100

# 调整权重
pavement rank -n 50 --grade-weight 0.6 --traffic-weight 0.2 --importance-weight 0.15 --cost-weight 0.05

# 详细模式
pavement rank --verbose
```

### 5. `budget` - 预算分配方案计算

#### 功能描述
在总预算约束下，按优先级从高到低依次分配养护资金，输出全额资助、部分资助及预算不足的明细清单。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `-t, --total` | float64 | 是 | 总预算金额（元），必须非负 |
| 权重参数 | - | 同 rank 命令 | 可自定义优先级权重 |

#### 养护费用估算模型

依据病害程度确定养护措施及单方造价：

| 指标类型 | 措施 | 评分区间 | 单价 (元/㎡) |
|---------|------|---------|--------------|
| IRI平整度 | 微表处 | ≥80分 | 55 |
| IRI平整度 | 薄层罩面 | 60-80分 | 120 |
| IRI平整度 | 铣刨重铺 | <60分 | 280 |
| 车辙深度 | 车辙填充 | ≥70分 | 180 |
| 车辙深度 | 结构补强 | <70分 | 320 |
| 裂缝密度 | 裂缝灌封 | ≥85分 | 35 |
| 裂缝密度 | 局部修补 | 65-85分 | 90 |
| 裂缝密度 | 铣刨重铺 | <65分 | 280 |

- 路面面积 = 路段长度(km) × 1000 × 7.5（标准车道宽度）
- 措施加权系数 = 各指标得分劣化比例
- 预估费用 = Σ(措施单价 × 加权系数) × 面积 / 10

#### 返回值说明

**预算概览**：
- 总预算、已分配金额（及占比）、剩余预算
- 全额资助路段数、部分资助数、预算不足数

**资金分配明细**：
- 路线编号、起止桩号
- 病害等级、长度
- 优先级评分
- 预估费用、实际分配金额
- 资助比例（%）
- 状态（全额资助 / 部分资助 / 预算不足）

#### 使用示例
```bash
# 基础预算分配（500万元）
pavement budget --total 5000000

# 5000万元预算并详细输出
pavement budget -t 50000000 --verbose

# 与优先级自定义权重结合
pavement budget -t 3000000 --grade-weight 0.55 --cost-weight 0.05
```

### 6. `export` - 导出Markdown养护方案报告

#### 功能描述
生成结构化的Markdown格式养护方案报告，包含病害分布统计、优先养护清单、预算分配方案三大核心部分。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `-o, --output` | string | 是 | 输出Markdown文件路径 |
| `--from` | string | 否 | 统计起始日期 |
| `--to` | string | 否 | 统计终止日期 |
| `--top` | int | 否 | 优先级Top N，默认50 |
| `--with-budget` | bool | 否 | 是否包含预算方案，默认true |
| `--total-budget` | float64 | 否 | 报告中的总预算金额，0则不显示 |

#### 报告结构

1. **报告基本信息**
   - 生成时间、工具版本、评定标准

2. **第一部分：病害分布统计**
   - 总体概况：总路段数、总里程、平均PCI
   - 病害等级分布表（数量、占比、里程）
   - 按路线分布统计表
   - 按养护中心分布统计表

3. **第二部分：优先养护路段清单 (Top 50)**
   - 排名、路线、桩号范围、长度
   - 病害等级、PCI分数、优先级分数
   - 预估费用、养护中心

4. **第三部分：预算分配方案**（启用时）
   - 预算概览、资助情况统计
   - 完整资金分配明细表

5. **第四部分：结论与建议**
   - 关键发现汇总
   - 编制建议清单

#### 使用示例
```bash
# 导出基础报告（不含预算部分）
pavement export -o ./reports/Q1_2024.md

# 导出包含500万预算的完整报告
pavement export -o ./reports/annual.md --total-budget 5000000

# 按日期范围筛选并导出Top 100
pavement export -o Q1_report.md --from 2024-01-01 --to 2024-03-31 --top 100
```

### 7. `stats` - 三维度数据统计分析

#### 功能描述
从路线、养护中心、病害等级三个维度统计路段数量、里程占比、病害分布情况。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `-d, --dim` | string | 否 | 统计维度：route/center/grade/all，默认all |
| `-o, --output` | string | 否 | 导出到Markdown文件 |

#### 维度说明

| 维度 | 统计字段 |
|------|---------|
| `route` - 按路线 | 路线编号、路段数、里程及占比、各等级病害数量 |
| `center` - 按养护中心 | 养护中心名称、路段数、里程及占比、各等级病害数量 |
| `grade` - 按病害等级 | 病害等级、路段数、里程及占比 |
| `all` - 全部维度 | 以上三项全部输出 |

#### 使用示例
```bash
# 查看全部维度统计
pavement stats

# 仅按路线维度
pavement stats --dim route

# 仅按养护中心维度
pavement stats -d center

# 统计并导出到文件
pavement stats -d all -o ./reports/statistics.md
```

### 8. `delete` - 批量删除历史数据

#### 功能描述
按检测批次号或日期范围批量清除历史检测数据，删除前提示确认。

#### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `-b, --batch` | string | 条件必填 | 待删除的批次号 |
| `-f, --from` | string | 条件必填 | 起始日期 YYYY-MM-DD |
| `-t, --to` | string | 条件必填 | 终止日期 YYYY-MM-DD |
| `--yes` | bool | 否 | 跳过交互确认直接删除 |

> **注意**：`--batch` 和 `--from/--to` 至少指定一项

#### 安全提示
- 删除前会显示当前数据库总记录数及待删除条件
- 默认需要输入 `y` 或 `yes` 进行二次确认
- 建议操作前先使用 `export` 命令备份

#### 返回值说明
- 删除前记录数
- 实际删除记录数
- 删除后剩余记录数

#### 使用示例
```bash
# 按批次号删除（交互确认）
pavement delete --batch Q1-2023

# 按日期范围删除
pavement delete --from 2022-01-01 --to 2022-12-31

# 自动确认删除（脚本中使用）
pavement delete -b OLD-DATA --yes --quiet
```

## 错误码说明

### ImportError - 数据导入错误

| 错误码 | 说明 | 修复建议 |
|--------|------|----------|
| IMP001 | 文件不存在 | 检查文件路径是否正确 |
| IMP002 | CSV格式无效 | 确保第一行为表头，使用标准逗号分隔 |
| IMP003 | 缺少必要列 | 确认包含路线编号、桩号、IRI、车辙、裂缝列 |
| IMP004 | 数据行无效 | 检查数据类型是否匹配，异常值是否过多 |
| IMP005 | 权限不足 | 检查目录/文件读取权限 |
| IMP006 | 空数据目录 | 确认目录中存在.csv文件 |

### ClassifyError - 病害判定错误

| 错误码 | 说明 | 修复建议 |
|--------|------|----------|
| CLA001 | IRI值不合法 | 确保IRI≥0 |
| CLA002 | 车辙深度不合法 | 确保车辙深度≥0 |
| CLA003 | 裂缝密度不合法 | 确保裂缝密度≥0 |
| CLA004 | 缺少判定数据 | 先执行import导入数据 |
| CLA005 | 自定义参数错误 | 确保权重和为1，阈值递减 |

### QueryError - 查询错误

| 错误码 | 说明 | 修复建议 |
|--------|------|----------|
| QUE001 | 路线编号不合法 | 格式应为G/S/T/X开头加数字 |
| QUE002 | 桩号格式错误 | 正确格式如K123+456 |
| QUE003 | 日期范围不合法 | 起始日期应早于终止日期 |
| QUE004 | 病害等级不合法 | 应为优/良/中/差或A/B/C/D |
| QUE005 | 无查询结果 | 放宽查询条件 |
| QUE006 | 数据库连接失败 | 检查db文件路径和权限 |

## 常见问题

**Q: 导入时出现"路线编号不合法"错误？**
A: 路线编号应遵循 G/S/T/X + 数字 的格式，例如 G108、S305。如果您的编号规范不同，请在CSV中将路线编号列值调整为符合要求的格式。

**Q: 如何处理缺少路段长度列的CSV？**
A: 系统会自动根据起止桩号计算路段长度（终止桩号 - 起始桩号），无需手动提供。

**Q: 优先级排序和预算分配时提示"没有记录"？**
A: 请按顺序执行：`import` → `classify` → `rank`/`budget`，确保前置步骤已完成。

**Q: 预算分配中出现很多"部分资助"是什么原因？**
A: 说明总预算不足以覆盖所有高优先级路段的全额费用，系统会按优先级尽可能分配，剩余路段只能部分资助或延期。

**Q: 数据库文件过大如何清理？**
A: 使用 `delete --batch` 或 `delete --from/--to` 清除历史批次数据，清理前建议先用 `export` 导出报告存档。
