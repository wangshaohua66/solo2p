# 婚庆服务全流程数字化管理系统 — 产品需求文档（PRD）

## 1. 产品概述

为某区域婚庆连锁集团（8 家门店、年均 1200 场婚礼）打造的全流程数字化管理平台，覆盖人员/场地/道具档期自动避让、套餐报价标准化、合同在线签署、财务自动核算与进度实时追踪。目标用户为门店运营负责人、策划师、财务人员与外部供应商（主持人、化妆师、摄影师、花艺师等）。系统旨在彻底替代 Excel 手工记录与微信群碎片化沟通，将旺季档期冲突赔付率降低 80% 以上、报价差异控制在 5% 以内、合同纠纷归零、供应商结算周期缩短 50%。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录入口 | 核心权限 |
|------|----------|----------|
| 集团管理员 | 主系统 | 全部门店数据、报价模板、财务总览、系统配置 |
| 门店运营 | 主系统 | 本门店婚礼创建、档期调度、合同签署、财务核算 |
| 策划师 | 主系统 | 个人接单、客户跟进、方案上传、进度更新 |
| 财务人员 | 主系统 | 收支明细、应收应付、绩效核算、报表导出 |
| 供应商（主持人/化妆师/摄影师/花艺师） | 供应商门户 | 个人档期查看、接单确认、提交服务凭证 |

### 2.2 功能模块

1. **工作台**：集团/门店运营 KPI 总览（成交额、待办婚礼、档期冲突预警、应收逾期），快捷操作入口。
2. **档期管理**：人员/场地/道具三类资源日历视图，创建任务时自动检测冲突并推荐可替换资源（500ms 内完成）。
3. **婚礼项目**：6 阶段（咨询/方案设计/合同签订/筹备执行/现场督导/后期交付）进度管理，关联档期、报价、合同、跟进。
4. **套餐报价**：基础套餐模板 + 按人数/服务项目/附加内容动态计价，门店差异化折扣系数，明细到单项成本与利润。
5. **合同管理**：套餐自动生成合同草稿，在线编辑条款、插入附加协议，电子签名远程签署，状态变更触发通知。
6. **客户跟进**：按婚礼倒计时自动生成任务清单（选婚纱/试妆/彩排等），策划师更新实时推送新人端，上传方案与现场照片。
7. **供应商门户**：独立登录入口，查看个人档期与接单，在线确认档期、提交服务凭证。
8. **财务核算**：每场婚礼收入成本明细，按月统计门店营收/人员绩效/供应商结算，应收应付逾期自动预警。
9. **报表统计**：时间维度成交额/转化率/客户满意度评分，支持导出 Excel 与 PDF。

## 3. 核心流程

**创建婚礼 → 档期避让 → 报价 → 合同 → 筹备跟进 → 财务结算**：策划师录入新人信息与婚期，系统自动从人员/场地/道具池匹配可用资源并检测冲突，对冲突项推荐可替换资源；选定资源后基于套餐模板与人数、附加项动态计算报价，生成合同草稿；新人远程电子签署后进入筹备阶段，系统按倒计时生成任务清单推送至新人端；策划师更新进度与上传凭证，现场督导与后期交付完成后，财务自动归集收入与成本生成明细表。

```mermaid

    A["录入新人信息与婚期"] --> B["自动匹配资源并检测冲突"]
    B --> C{"存在冲突?"}
    C -- 是 --> D["推荐可替换资源"]
    D --> B
    C -- 否 --> E["基于套餐动态计算报价"]
    E --> F["生成合同草稿"]
    F --> G["新人远程电子签署"]
    G --> H["按倒计时生成任务清单"]
    H --> I["策划师更新进度并推送新人"]
    I --> J["现场督导与后期交付"]
    J --> K["财务归集收入成本生成明细"]
```

## 4. 界面设计

### 4.1 设计风格

- **设计方向**：精炼编辑奢华风（Refined Editorial Luxury）。以婚庆的仪式感与仪式后的庄重为基调，规避俗套的粉紫渐变。
- **主色**：深酒红茄紫 `#5B2A4E`（沉稳仪式感）；**辅色**：香槟金 `#C9A86A`（点缀高光）；**背景**：象牙白 `#FBF8F3`；**卡片表面**：纯白带极淡暖色 `#FFFFFF`；**成功/警告/危险**：墨绿 `#3F7D58` / 琥珀 `#D9952B` / 砖红 `#B4452E`。
- **按钮风格**：主按钮采用酒红→茄紫渐变 + 微光泽，圆角 10px，hover 抬升投影；次按钮描边香槟金。
- **字体**：展示字 `Cormorant Garamond`（拉丁衬线，优雅）+ 中文展示 `Noto Serif SC`；正文 `Noto Sans SC`；数字与数据采用 `Sora` 等宽风格以增强可读性。
- **布局**：左侧固定导航菜单（深色玻璃质感），主内容区卡片式布局，关键数据用大号衬线数字呈现，留白克制而舒展。
- **图标**：线性描边图标（Lucide 风格），与香槟金描边呼应。
- **动效**：页面加载错位淡入（staggered reveal），卡片 hover 微抬升，日历拖拽流畅过渡，骨架屏加载。

### 4.3 响应式

桌面优先（≥1200px 全功能），平板（768–1199px 折叠侧栏为图标栏、表格转卡片），手机（<768px 底部 Tab 导航、关键页面如工作台与档期日历精简为日表式）。触控优化：按钮≥44px、日历支持滑动手势。

### 4.4 3D 场景

本项目无 3D 场景需求。

## 5. 性能与约束

- 婚礼创建与档期查询接口响应 < 800ms；档期冲突检测算法 < 500ms；合同 PDF 生成 < 3s。
- 支持 200 并发；热点档期数据 Redis 缓存 TTL 30 分钟。
- 数据库承载 3 年约 50 万场婚礼记录。
- 前后端请求参数采用 JSR-303 注解校验（前端以同等规则做实时校验）。
- 每日定时任务清理过期会话与临时文件。
