## 1. 产品概述

月子中心智能运营管理系统，面向区域连锁月子中心（8家门店、400间套房、年均接待2500人次产妇），提供房间预订、护理排班、月子餐定制、探视登记、康复预约、运营报表六大核心模块的一体化数字运营平台。

- **主要目的**：替代Excel表格与电话沟通的落后模式，消除重复预订、漏餐、时段冲突等运营痛点，实现多门店房态实时同步与全流程可追溯管理
- **目标用户**：店长、护理主管、护士、营养师、康复师、前台接待员
- **市场价值**：降低人工统计耗时80%以上，提升房间利用率与客户满意度，为连锁化扩张提供数字化底座

### 2.2 功能模块

1. **多门店房态看板**：日历热力图展示各门店房间占用状态，拖拽调整预订日期，自动冲突检测与跨门店同步
2. **护理排班智能助手**：按资质自动匹配可排班人员，批量排班、换班审批、电子签名交接、夜班记录补录提醒
3. **月子餐全流程追溯**：体质辨证生成食谱，厨房分餐次制作看板，扫码确认、漏餐预警、忌口拦截
4. **探视时段智能分流**：分时段预约探视、错峰推荐、身份登记与人脸采集、超时逗留提醒
5. **康复项目时段管理**：时间线展示康复师安排、项目时长自定义、冲突检测、进度追踪
6. **运营数据驾驶盘**：月度入住率、护理服务量、餐品消耗、康复收入多维度图表，同比环比分析

## 3. 核心流程

### 3.1 产妇入住全流程

店长或前台在房态看板选择空闲房间，录入产妇基本信息与入住日期，系统自动检测预订冲突并锁定房间；入住当日办理入住手续，房间状态由黄色（预订）转为红色（入住）；护理主管根据产妇情况排班，营养师进行体质辨证并生成月子餐食谱，康复师预约产后康复项目；住馆期间（平均28天）持续提供护理与餐食服务；满月出馆时房间状态恢复空闲。

```mermaid
    "实地看房" --> "签约入住"
    "签约入住" --> "护理排班"
    "签约入住" --> "体质辨证"
    "签约入住" --> "康复预约"
    "护理排班" --> "每日护理服务"
    "体质辨证" --> "每日六餐制作"
    "康复预约" --> "康复项目执行"
    "每日护理服务" --> "满月出馆"
    "每日六餐制作" --> "满月出馆"
    "康复项目执行" --> "满月出馆"
    "满月出馆" --> "房间释放"
```

### 3.2 月子餐制作流转流程

营养师根据产妇体质（气虚、血虚、阴虚、阳虚）辨证，生成个性化食谱并标注忌口食材；厨房看板显示待制作餐品列表，按餐次（早、早点、午、午点、晚、晚点）分类；厨师制作完成后扫码确认，系统自动检测忌口食材并拦截；餐品送达后状态流转为已送达，系统记录全程时间节点；若临近用餐时间仍有未制作餐品，触发漏餐预警。

### 3.3 护理排班与交接流程

护理主管进入周视图排班表，系统按护士资质（新生儿护理证、产后护理证）自动筛选可排班人员；主管批量排班后提交，护士在排班表查看个人班次；换班需发起申请，主管审批通过后生效；交接班时双方电子签名确认，系统记录交接内容；夜班结束后系统自动提醒补录护理记录（如婴儿喂养详情）。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：粉色温馨色调体系，主色 `#E891A8`（暖玫粉），辅助色 `#F5E0E6`（淡粉背景），强调色 `#C66B85`（深玫红），中性色 `#4A4A4A`（深灰文字）
- **状态色**：空闲绿色 `#5CB85C`、预订黄色 `#F0AD4E`、入住红色 `#D9534F`、维修灰色 `#999999`
- **按钮风格**：圆角胶囊形（border-radius: 20px），主按钮带柔和阴影，悬停微抬起动效
- **字体**：标题使用"霞鹜文楷"（LXGW WenKai）体现温馨人文感，正文使用"思源黑体"（Noto Sans SC）保证可读性
- **布局风格**：顶部固定导航栏 + 左侧折叠式功能菜单 + 右侧卡片式主内容区
- **图标风格**：Bootstrap Icons 圆润线条风格，配合粉色系填充
- **氛围细节**：卡片带柔和粉色渐变背景，房间色块带微光内阴影，数据看板背景带噪点纹理增加质感

### 4.3 响应式

- 桌面优先设计，基准宽度1440px，适配平板横屏（1024px）与手机竖屏（375px）
- 平板横屏：左侧菜单可折叠为图标条，卡片网格从四列降为两列
- 手机竖屏：左侧菜单隐藏改为底部Tab栏，房态看板由月历切换为列表视图，排班表纵向滚动
- 触控优化：拖拽操作增大触摸区域（最小44x44px），按钮间距加大，禁用悬停靠悬停触发的交互
