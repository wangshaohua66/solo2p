# 光影院线运营管理平台 - 产品需求文档（PRD）

## 1. 产品概述

光影院线运营管理平台是面向区域连锁电影院线的全链路数字化运营系统，覆盖排片、DCP调度、售票、会员、卖品、票房分析、影厅监控七大业务域，解决排片靠Excel手动协调、DCP流转混乱、会员积分各店割裂、卖品库存脱节、票房汇总滞后、节假日排队等六大痛点。

- 服务对象：院线管理层、影院经理、排片员、售票员、卖品员五类角色
- 业务规模：支撑15家影院、120块银幕、年放映15万场、年接待800万人次
- 价值目标：排片冲突率下降、首映延误清零、积分通兑通刷、卖品周转优化、数据实时化、高峰体验提升

## 2. 核心功能

### 2.1 用户角色

| 角色 | 入口方式 | 核心权限 |
|------|---------|---------|
| 院线管理层 | 账号登录 | 全院线数据看板、跨影院分析、统筹审批 |
| 影院经理 | 账号登录 | 本影院运营总览、排片审批、卖品管理 |

| 售票员 | 账号登录 | 选座售票、退改签、会员核销 |
| 卖品员 | 账号登录 | 卖品入库出库、盘点、收银结算 |

### 2.2 功能模块

1. **工作台首页**：院线核心指标看板、今日排片概览、待办预警、影院业绩排行
2. **智能排片**：拖拽式周/月日历排片、冲突自动检测、排片权重推荐、场次复制
3. **DCP调度追踪**：拷贝流转借调、位置状态追踪、首映日预警、调拨审批
4. **在线选座购票**：SVG座位图、实时锁定防重复、二维码电子票、订单流程
5. **会员通兑体系**：会员等级、积分余额、优惠券包、跨店积分、生日权益
6. **卖品进销存**：SKU采购入库、领用出库、盘点调整、销量毛利、低库存补货
7. **票房数据中心**：实时票房聚合、多维分析、日周月报、影片/时段/影院维度
8. **影厅状态监控**：TMS对接、放映状态、设备告警、温湿度环境数据

## 3. 核心流程

### 3.1 智能排片流程
排片员进入日历视图→拖拽影片到影厅时间格→系统自动检测时间冲突/容量/时长清洁间隔→给出排片权重建议→确认保存→生成场次→同步至售票与监控。

### 3.2 在线选座购票流程
观众选择影片场次→展示SVG座位图→点击座位实时锁定（防重复下单）→确认订单→选择会员积分抵扣→支付→生成二维码电子票→扫码入场。

### 3.3 DCP调度流程
排片确认场次→系统匹配可用DCP拷贝→若需跨院线借调则发起调拨→追踪在途状态→首映日倒计时预警→拷贝到达入库→放映完毕归还。

## 4. 用户界面设计

### 4.1 设计风格

**设计理念：「胶片暗金 Cinematic Noir」**

将院线控制台的权威感与影院空间的沉浸氛围融合。深炭色背景如关灯后的影厅，金色与琥珀光晕如放映机投射的暖光与影院金字招牌，绛红点缀如绒幕与座椅，胶片齿孔纹理与微弱颗粒噪点强化电影语境。

- **主色调**：深炭黑 `#0B0B12` / 墨蓝面 `#15151F` 为底；影院金 `#E8B547` 为主强调；绛红 `#C8364F` 为次强调；金琥珀渐变用于关键数据与按钮
- **按钮风格**：金琥珀渐变主按钮带柔光投影，次要按钮描边玻璃态，圆角 8px
- **字体**：标题采用衬线体 `Cinzel`+`Noto Serif SC` 营造影院铭牌质感，正文采用 `Noto Sans SC` 保证管理后台可读性，数字采用 `Oswald` 强化仪表盘观感
- **布局**：左侧深色固定导航栏 + 右侧内容区，顶部状态栏，卡片式信息分组
- **图标/装饰**：胶片齿孔边框、放映机光束、微弱颗粒噪点、金线分隔，关键状态用脉冲动效

### 4.3 响应式

桌面优先（管理后台以 1440px 为主视口），侧边栏可折叠，内容区栅格自适应。关键看板与座位图在小屏自动收窄为单列堆叠，触摸手势支持座位图缩放与日历横向滚动，满足移动端选座购票场景。

### 4.4 视觉细节增强

- 全局胶片颗粒噪点叠加层（低透明度）营造质感
- 卡片顶部金线高光 + 底部投影分层
- 数据加载采用放映机光束扫描动效
- 关键数字采用 CountUp 数字滚动入场
- 悬浮态金色描边发光过渡
